# Sites

Cross-project memory for the scroll-page skill. One line per finished site, appended at the end of Step 7. The structure step reads this file: a new site must differ from every line here on at least one of grammar, nav, hero and close, because a page that only changes world is a re-skin of a page that already exists.

Columns: date (YYYY-MM-DD), project (repo or folder name), grammar (one of grammars.md section 2, or a named new one), nav (what the chrome is), hero (what the first screen does), close (how the last screen behaves and what the CTA sits in), signature move (one phrase).

Lines are append-only. A site that was later redesigned keeps its line, because the shape it used is still a shape that was used.
